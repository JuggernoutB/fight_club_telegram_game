# 🗡️ Fight Club Sprite Animator

A web-based sprite animation tool for testing and previewing fighter character animations.

## 🎯 Features

- **Multi-file Upload**: Upload multiple sprite frames at once
- **Smart Sorting**: Automatically sorts files by number (elf_1.png, elf_2.png, etc.)
- **Configurable Speed**: Adjust animation speed from 1-30 FPS
- **Continuous Looping**: Plays animations endlessly until stopped
- **Format Support**: PNG, JPG, JPEG, GIF (PNG recommended for games)
- **Responsive Design**: Works on desktop and mobile devices

## 🚀 How to Use

1. Open `index.html` in your web browser
2. Click "Choose Sprite Files" and select your animation frames
3. Adjust the speed slider (1-30 FPS)
4. Click ▶️ Start to begin animation
5. Click ⏹️ Stop to pause animation

## 📁 File Naming Convention

For best results, name your sprite files with numbers:
- `elf_1.png`
- `elf_2.png`
- `elf_3.png`
- `orc_idle_1.png`
- `orc_idle_2.png`

The animator will automatically sort and sequence your frames correctly.

## 🎮 Recommended Format

**PNG** is the best format for game sprites because:
- ✅ Supports transparency
- ✅ Lossless compression
- ✅ Perfect for pixel art
- ✅ Wide browser support

## 📊 Features Overview

- **Animation Info Panel**: Shows frame count, current frame, total file size
- **Smooth Controls**: Intuitive start/stop buttons
- **Real-time Updates**: Live frame counter during animation
- **File Management**: Automatic sprite loading and organization

Perfect for testing character animations before integrating them into your Fight Club game!
